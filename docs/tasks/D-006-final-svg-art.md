# D-006 Фінальний арт як детальні SVG
Залежить від: —
Виконавець: designer (3 екземпляри паралельно — частини A/B/C)

## Мета
Замовник не генерує арт — фінальний арт робимо самі як детальні SVG у `assets/art/final/` (гра бере їх замість плейсхолдерів). Стиль і опис кожного ассета — у `docs/art-prompts.md` (той самий зміст, що промпти, але намальований вектором). Палітра GDD §8: фон #14161f, кістка #e8e2d0, червоний #a8322d, синій #3b5a8a, золото #c9a24b.

## Вимоги до всіх файлів
- Імена й розміри (`width`/`height`/`viewBox`) — ТОЧНО як у відповідного плейсхолдера `assets/art/placeholder/<ім'я>.svg` (відкрий його і збережи композицію: напрям погляду, положення, вільні зони під UI).
- Значно детальніше за плейсхолдер: градієнти (linear/radial), тіні, обвідка, світло, текстури штрихами; єдиний стиль між усіма файлами.
- Лише чистий SVG 1.1: без `<image>`, зовнішніх посилань, шрифтів крім generic `serif`, без фільтрів `feTurbulence`/`feDisplacementMap` (повільний імпорт) — простий `feGaussianBlur` можна. Розмір файлу ≤ 150 КБ.
- Прозорий фон для персонажів, ворогів, рамок, лого.

## Частина A — фони + лого
`bg_menu`, `bg_map`, `bg_combat`, `bg_merchant`, `bg_rest`, `bg_sanctuary` (1080x1920; центр/низ спокійний і темніший під UI), `logo` (900x300).

## Частина B — персонажі і вороги
`player_knight`, `player_mage`, `enemy_skeleton_warrior`, `enemy_skeleton_archer`, `enemy_ghoul`, `enemy_wraith`, `enemy_dark_cultist`, `enemy_bone_minion`, `enemy_bone_golem`, `enemy_lich_lord`. `player_mage_locked` НЕ малювати.

## Частина C — рамки карт
`card_frame_attack`, `card_frame_skill`, `card_frame_power`. Геометрію (де назва, вартість, вікно опису) візьми з плейсхолдера 1:1 — гра кладе текст поверх у тих самих координатах; змінюй лише оздоблення.

## Готово, коли
Усі файли своєї частини існують у `assets/art/final/`, валідні SVG (перевір, що XML парситься), розміри як у плейсхолдерів.
