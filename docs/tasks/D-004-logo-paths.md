# D-004 Логотип без SVG text
Залежить від: —
Виконавець: designer

## Мета
Godot не рендерить `<text>` у SVG — напис "CardFight" у `assets/art/placeholder/logo.svg` не видно.

## Кроки
- [ ] Перероби `logo.svg` (900x300, та сама композиція й палітра): літери "CardFight" — лише `<path>`/`<polygon>`/`<rect>` (геометричний serif-подібний шрифт власноруч, кутасті засічки), жодного `<text>`, `<font>`, `<use>` на зовнішні ресурси, без фільтрів.

## Готово, коли
У файлі немає `<text`; напис читається як "CardFight".
