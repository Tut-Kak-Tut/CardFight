# D-005 Промпти фінального арту
Залежить від: —
Виконавець: designer

## Мета
Документ `docs/art-prompts.md` з готовими до вставки промптами для генератора (Midjourney v6 / Leonardo / SDXL), щоб замовник згенерував фінальний арт. Стиль — темне фентезі, палітра GDD §8 (фон #14161f, кістка #e8e2d0, червоний #a8322d, синій #3b5a8a, золото #c9a24b), єдиний стиль для всіх ассетів.

## Що потрібно (імена = імена плейсхолдерів у `assets/art/placeholder/`, але `.png`)
- Фони 1080x1920 (9:16): `bg_menu`, `bg_map`, `bg_combat`, `bg_merchant`, `bg_rest`, `bg_sanctuary` — центр/низ спокійний під UI.
- Персонажі (прозорий фон, квадрат): `player_knight`, `player_mage`. `player_mage_locked` НЕ генерувати (гра робить силует сама).
- Вороги (прозорий фон, квадрат): `enemy_skeleton_warrior`, `enemy_skeleton_archer`, `enemy_ghoul`, `enemy_wraith`, `enemy_dark_cultist`, `enemy_bone_minion`, `enemy_bone_golem` (еліта), `enemy_lich_lord` (бос, епічніший).
- Рамки карт (≈ 12:17), центр-вікно під текст: `card_frame_attack` (червона), `card_frame_skill` (синя), `card_frame_power` (золота).
- `logo` (3:1), напис "CardFight".
- Іконки/реліквії/статуси/вузли мапи лишаються SVG — не генерувати.

Подивись наявні плейсхолдери, щоб зберегти композицію (куди дивиться персонаж — вправо, вороги — вліво тощо).

## Формат документа
1. «Загальний стиль» — суфікс, що додається до кожного промпту, + негативний промпт.
2. Список: файл → `--ar` → промпт.
3. Інструкція для замовника (5-7 рядків): як прибрати фон (функція генератора / remove.bg / Canva), зберегти PNG з потрібним іменем у `assets/art/final/`, рекомендовані розміри (фони 1080x1920, персонажі/вороги 512x512, рамки 480x680, лого 900x300).
