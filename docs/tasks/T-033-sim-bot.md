# T-033 Інструмент симуляції забігів з розумним ботом
Залежить від: —
Модель: sonnet

## Мета
Тестерський бот (`docs/reports/tools/sim_runs.gd`, policy smart) дав Mage 0.3% win-rate, Knight 29%. Mage, ймовірно, програє через бота, який не грає синергію отрути/Focus/добору. Потрібен постійний інструмент `tools/sim.gd` з ботом, що грає «як середній гравець», щоб балансер міг спиратися на числа.

## Файли
Створити: `tools/sim.gd` (`extends SceneTree`, лише core-логіка, без сцен). Можна взяти за основу `docs/reports/tools/sim_runs.gd` (скопіюй і поліпш; оригінал не змінюй).

## Кроки
- [x] 1. Запуск: `"$GODOT" --headless --path . -s tools/sim.gd -- <runs=300> <character=all|knight|mage>`. Детерміновані сиди. Вихід: таблиця на персонажа — win-rate, % смертей по шарах/типу бою (normal/elite/boss), середня к-сть ходів гравця, HP на вході до боса, gold зароблено/витрачено, shards, середній розмір колоди.
- [x] 2. Бій — бот з оцінкою карт (жадібний пошук на хід): перебирай порядки розіграшу руки в межах енергії (рука ≤ 10 — можна обмежений перебір/beam ~200 станів) і оцінюй кінцевий стан: шкода/вбивства ворогів, поглинутий блоком вхідний урон (за намірами ворогів), накладена отрута × очікувані ходи, баффи (strength, focus тощо) з вагою на залишок бою, добір карт ≈ +цінність, штраф за втрачене HP. Клонуй стан бою для перебору, якщо core дозволяє; якщо ні — евристики з пріоритетами (летальне → блок під вхідний урон → баффи на початку бою → отрута → шкода).
- [x] 3. Поза боєм: вибір карти в нагороді за простою оцінкою (синергія з архетипом персонажа: для Mage — poison/draw/focus, для Knight — strength/block), пропуск слабких карт; торговець — видалення базових Strike/Defend, купівля сильних карт/реліквій якщо вистачає; вогнище — лікування якщо HP < 50%, інакше покращення; мапа — уникати еліт при HP < 60%.
- [x] 4. Прожени 300 забігів на кожного персонажа, впиши результат у `docs/reports/sim-2026-10-04.md` (таблиця + 3-5 рядків висновків: що саме вбиває Mage, які карти бот бере/грає найчастіше).
- [x] 5. Додай рядок команди в docs/plan.md «Запуск».

## Готово, коли
`tools/sim.gd` працює однією командою за < 5 хв на 300×2 забігів; звіт з таблицею існує. Числа балансу НЕ змінюй.
