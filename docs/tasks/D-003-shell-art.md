# D-003 Арт оболонки (плейсхолдери SVG)
Залежить від: —
Виконавець: designer

## Мета
SVG-плейсхолдери для Main Menu, Character Select, Sanctuary, Pause/Settings у стилі наявних `assets/art/placeholder/*.svg` (темне фентезі, палітра GDD §8: фон #14161f, кістка #e8e2d0, червоний #a8322d, синій #3b5a8a, золото #c9a24b).

## Файли (створити в `assets/art/placeholder/`)
- `bg_menu.svg` 1080x1920 — вхід у підземелля / арка, похмуро, центр вільний під кнопки.
- `bg_sanctuary.svg` 1080x1920 — святилище, свічки/вівтар, світліше за меню.
- `logo.svg` ~900x300 — напис "CardFight" (текст як контури або `<text>` з generic serif), кістка + золото.
- `icon_shard.svg` 128x128 — Soul Shard (синьо-фіолетовий кристал-душа).
- `icon_lock.svg` 128x128 — замок.
- `icon_settings.svg` 128x128 — шестерня.
- `icon_pause.svg` 128x128 — дві вертикальні смуги.
- `player_mage_locked.svg` — силует Mage (той самий розмір/кадр, що `player_mage.svg`), суцільна темна заливка + слабкий контур.

## Готово, коли
Усі 8 файлів існують, валідні SVG, розміри як вказано.
