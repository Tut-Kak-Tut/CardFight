# D-001 Плейсхолдер-арт для бою
Виконавець: designer

## Мета
Прості SVG-плейсхолдери (геометрія, силуети), щоб бій виглядав читабельно. Стиль: темне фентезі, плоскі форми, товсті контури.
Палітра: фон #14161f, кістка #e8e2d0, кривавий червоний #a8322d, приглушений синій #3b5a8a, золото #c9a24b.
