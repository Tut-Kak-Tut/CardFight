# Бриф — CardFight (робоча назва)

## Продукт
Мобільна 2D карткова roguelike-гра (deckbuilder) у дусі Slay the Spire.

## Core loop (від замовника)
Вибір колоди і персонажа → підземелля (бої, торговці, в кінці нагорода) → назад до вибору колоди.

## Рішення
| Питання | Відповідь |
|---|---|
| Рушій | Godot 4 (GDScript) |
| Платформа | Android, портретна орієнтація (iOS — пізніше) |
| Бій | Покроковий як Slay the Spire: енергія на хід, рука карт, вороги показують намір |
| Підземелля | Карта з розгалуженнями: вузли бій / торговець / еліта / бос у кінці |
| Прогресія між забігами | Мета-прогресія: нагорода відкриває нові карти і персонажів назавжди |
| Сеттинг | Темне фентезі (лицарі, маги, скелети, підземелля) |
| Графіка | Спершу плейсхолдери (прості SVG/фігури від дизайнера), потім промпти для генератора арту |
| Обсяг MVP | Малий: 2 персонажі, ~30 карт, 1 підземелля ~10 вузлів, 5-6 ворогів + бос, торговець |

## Уточнення після GDD (раунд 3)
- «Вибір колоди» = вибір персонажа з фіксованою стартовою колодою; відкриті карти з'являються в нагородах і в торговця.
- Додати вузол «Відпочинок» (вогнище: лікування АБО покращення карти). Подій у MVP немає.
- Мова інтерфейсу: лише англійська (усі тексти в грі англійською).
- Туторіалу і монетизації в MVP немає. Назви — робочі.
- Цільовий забіг: ~20-30 хв, win-rate новачка ~30-40%.
- Android мінімум API 24 (Android 7), портрет 1080x1920 базова роздільність.
